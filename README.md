# صالون حسام

موقع صالون حلاقة للشباب: افتتاحية بعمود حلاق ثلاثي الأبعاد، أسعار بالشيكل، وحجز أونلاين بالأيام والساعات مع منع الحجز المزدوج.

بدون أي build. ملفات HTML/CSS/JS عادية، بتشتغل على GitHub Pages مباشرة.

## شو فيه

**للزبون (`index.html`)**
- افتتاحية: الكاميرا بتبلش قريبة على خطوط العمود وبترجع لورا لحد ما يبين كامل، بعدين بيطلع الاسم وزر «ادخل». العمود بعدها بيتحرك على جنب بالهيرو وبيطلع لفوق مع السكرول.
- حالة الصالون هلّق (مفتوح لحد كذا / مسكّر) محسوبة من ساعات الدوام.
- الأسعار بالشيكل. الضغط على أي خدمة بيختارها بالحجز مباشرة.
- قسم «الطريقة» بسكرول أفقي مثبّت.
- معرض صور (بيظهر أوتوماتيك لما الإدارة تضيف صور).
- الحجز: خدمة ← يوم ← ساعة ← اسم وتلفون. الأوقات المحجوزة بتبين مشطوبة وما بتنكبس. التذكرة على الجنب بتتعبّى وإنت ماشي، وبالآخر في ختم «محجوز».
- بعد الحجز: كود حجز، زر واتساب للصالون برسالة جاهزة، وزر «ضيف للتقويم» (ملف .ics مع تذكير قبل ساعة).
- إلغاء الحجز بالكود + رقم التلفون.
- الأوقات بتتحدّث كل 30 ثانية، ولو اثنين حاولوا ياخدوا نفس الوقت، الثاني بتطلعله رسالة وبتتحدث الساعات.

**للإدارة (`admin.html`، الرمز الأولي `4040`)**
- الحجوزات لكل يوم مع الأوقات الفاضية بينهم، وأزرار: تم / ما إجا / إلغاء / واتساب للزبون (رسالة تذكير جاهزة) / اتصال.
- إحصائيات: الدور الجاي، حجوزات ودخل اليوم، دخل آخر 7 أيام.
- حجز يدوي (لزبون اتصل) أو تسكير وقت (استراحة مثلاً).
- الخدمات والأسعار: إضافة، تعديل السعر بالشيكل والمدّة، إخفاء، حذف.
- ساعات الدوام لكل يوم، كل كم دقيقة في دور، لكم يوم لقدّام الحجز مفتوح، وأيام عطلة محددة.
- رفع صور (بتنضغط تلقائياً).
- معلومات التواصل (تلفون، واتساب، انستغرام، تيك توك، عنوان، خريطة) وتغيير الرمز.

## ربط قاعدة البيانات (ضروري حتى الحجوزات توصل من كل الأجهزة)

بدون ربط، الموقع بيشتغل «وضع تجريبي» والحجوزات بتنحفظ على نفس الجهاز بس.

1. اعمل مشروع جديد على [supabase.com](https://supabase.com) (مجاني).
2. افتح **SQL Editor** ← New query، الصق محتوى `supabase/schema.sql` كامل واضغط **Run**.
3. من **Project Settings ← API** انسخ `Project URL` و الـ `anon / publishable key`.
4. حطهم بـ `js/config.js`:
   ```js
   export const SUPABASE_URL = 'https://xxxx.supabase.co';
   export const SUPABASE_KEY = 'sb_publishable_...';
   ```
5. ادخل على `admin.html` بالرمز `4040` وغيّره فوراً من «الإعدادات».

### ليش ما في حجز مزدوج؟

القاعدة نفسها فيها قيد (`exclusion constraint`) بيرفض أي حجزين متداخلين بنفس اليوم. يعني حتى لو اثنين ضغطوا «ثبّت» بنفس اللحظة بالضبط، واحد بس بينحفظ. انجرّب بـ 20 طلب متزامن على نفس الوقت، وانحفظ واحد بس.

### الأمان

- الزبون ما بيقدر يشوف أسماء أو أرقام حدا. بيشوف بس الأوقات المشغولة.
- كل تعديل (أسعار، حجوزات، دوام، صور) بيمر عبر دوال بتتحقق من الرمز داخل القاعدة. الرمز مخزّن مشفّر (bcrypt).
- بعد 8 محاولات رمز غلط، الدخول بينقفل 15 دقيقة.
- المفتاح اللي بـ `config.js` هو المفتاح العام، آمن يكون بالمتصفح.

## النشر على GitHub Pages

Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` / `(root)` ← Save.
بعد دقيقة بيصير الموقع على `https://<username>.github.io/salon/`.
